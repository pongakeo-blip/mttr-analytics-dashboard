# 📊 Work Analytics Dashboard

Dashboard สำหรับติดตามและวิเคราะห์ชั่วโมงการทำงานและจำนวน Ticket แบบ real-time

## ✨ Features

- 📈 กราฟแสดงข้อมูลแบบ interactive
- 🎯 เส้น baseline เพื่อเปรียบเทียบประสิทธิภาพ
- ✏️ แก้ไขข้อมูลได้เองผ่าน UI
- 📱 Responsive design รองรับทุกอุปกรณ์
- 🎨 Dark theme ดูสบายตา
- ➕ เพิ่ม/ลบข้อมูลเดือนได้
- 📊 สถิติอัปเดตอัตโนมัติ

## 🚀 Quick Start

เปิดไฟล์ `index.html` ในเว็บเบราว์เซอร์ หรือเข้าผ่าน GitHub Pages:

```
https://[your-username].github.io/work-analytics-dashboard/
```

## 📖 วิธีใช้งาน

1. คลิกปุ่ม **"แสดงตัวแก้ไข"** เพื่อเปิดส่วนจัดการข้อมูล
2. แก้ไขข้อมูลในช่องที่ต้องการ:
   - ชื่อเดือน
   - ชั่วโมงการทำงาน
   - จำนวน Ticket
   - ค่า Baseline
3. กดปุ่ม **"อัปเดตกราฟ"** เพื่ออัปเดตการแสดงผล
4. ใช้ปุ่ม **"เพิ่มเดือน"** เพื่อเพิ่มข้อมูลเดือนใหม่
5. ใช้ปุ่ม **"รีเซ็ต"** เพื่อกลับไปใช้ข้อมูลเริ่มต้น

## 🛠️ Tech Stack

- HTML5
- CSS3 (with CSS Variables)
- JavaScript (Vanilla)
- Chart.js
- Google Fonts (IBM Plex Sans Thai, JetBrains Mono)
